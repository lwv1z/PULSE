Privacy Policy

Last updated: August 2026

Money Beats is a personal automation tool built and operated by a single individual for uploading video content to their own YouTube channel. It is not distributed to or used by any other person or organization.

Use of YouTube API Services

Money Beats uses YouTube API Services. By using Money Beats, the operator acknowledges and agrees to be bound by the YouTube Terms of Service.

Google's own privacy practices are described in the Google Privacy Policy.

What data this application accesses

Money Beats uses the YouTube Data API solely to upload video files, titles, descriptions, and tags to the operator's own YouTube channel via the videos.insert endpoint. It does not read, collect, store, or share any data from YouTube, Google, or any other party, and does not access any other user's account or data. No data belonging to any third party is ever processed.

Data retention and deletion

Money Beats stores only the content it generates for its own operator's channel (video files, titles, descriptions) on the operator's own private infrastructure. No data is retained by any third party. The operator can revoke this application's access to their Google Account at any time via Google Account permissions, which immediately and permanently revokes all API access.

No personal data is collected from visitors to this page.
